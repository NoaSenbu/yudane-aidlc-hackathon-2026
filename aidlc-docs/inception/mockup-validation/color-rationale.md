# 配色設計判断書 — Color Rationale

> モックアップ（`mockup/styles.css`）で採用した **Indigo + Cold Rose #E8B4D0 + Cyan #4DE1FF** の 3 色構成について、採用理由・不採用色との対比・UX 倫理上の役割分担を明文化する。

---

## 1. 採用した 3 色の定義

`mockup/styles.css` の `:root` より抜粋:

```css
:root {
  /* Base (deep, cold) */
  --bg-0: #05070F;
  --bg-1: #0A0E2A;
  --bg-2: #121633;

  /* Accents (not energetic, but strategic) */
  --rose: #E8B4D0;       /* Cold Rose */
  --rose-deep: #B987C7;
  --cyan: #4DE1FF;
  --gold: #D4B062;
  --red: #FF6B8A;
}
```

### 1.1 3 色の設計意図

| 色 | HEX | 役割 | 画面上の使用 |
|---|---|---|---|
| **Indigo 深夜** | `#05070F` → `#0A0E2A` → `#121633`（3 段グラデーション） | 瞑想的誘惑、夜間利用の文脈演出 | ホーム背景、論破モーダル背景 |
| **Cold Rose** | `#E8B4D0` | 温かく見えて実は冷たい「友達のフリ」 | AI 発話バルーン、称号バッジ、CTA グラデーション |
| **Cyan** | `#4DE1FF` | 外部遷移（Amazon 出口）の示唆 | Amazon で買うボタン、Share Link、ライブドット |

---

## 2. なぜこの 3 色なのか

### 2.1 Indigo 深夜 — 「判断が鈍る時間」の色

- YUDANE の KPI「深夜帯（22〜2 時）利用比率 30%+」（要件書 §6.1）は、**判断力が低下する時間帯の利用を想定** している
- 明るい白背景では「朝の冷静な決断」を想起させてしまい、論破モーダルの効果が薄れる
- Indigo の深い青紫は、**夜の瞑想的な状態** を背景に置くことで、論破コピーの侵入を妨げない

### 2.2 Cold Rose `#E8B4D0` — 「友達のフリ」の色

- 要件書 §2.2 で定義したコピートーン「友達系」に対応する UI 色
- 純粋な赤（警告）でも純粋なピンク（感情）でもなく、**冷ややかさを帯びた薄紫ピンク**
- 「信頼できる友人が論破してくる」が、その親密さが **実は収益化のための演出** であることを、色自体で暗示
- `rose-deep #B987C7` へのグラデーションで AI 発話の「少しずつ深くなる」感じを演出

### 2.3 Cyan `#4DE1FF` — 「出口」の色

- Amazon Associates Special Link（外部遷移）は YUDANE のビジネスモデルの核（§0.1 収益モデル）
- Cyan は他の色から明確に浮き、**「ここから外に出る」** の視覚言語として機能
- ライブドット（YUDANE 稼働中インジケータ）にも使用し、「常時起動のインフラ感」を演出

---

## 3. 採用しなかった色の対比

### 3.1 赤系（警告・緊急）— 不採用

| 色 | 連想 | なぜ YUDANE に合わないか |
|---|---|---|
| `#FF0000` 純赤 | 警告、緊急 | **撤退を促す色**。YUDANE は逆に「もう 1 タップして」を演出したい |
| `#FF4444` ソフト赤 | 誤り、禁止 | 論破モーダルが「間違っている」印象に転換される |

**結論**: 赤系はダメ化ループとポジティブ感情の接続を阻害する。ただし **NG-6 精神衛生境界発動時** など、撤退を促すべき瞬間には `red #FF6B8A` をアクセント限定で使用。

### 3.2 黄色系（注意・視認性）— 不採用

| 色 | 連想 | なぜ YUDANE に合わないか |
|---|---|---|
| `#FFD700` ゴールド | 高級、達成 | Amazon 公式のオレンジ系（`#FF9900`）と衝突、Share Extension 遷移時に違和感 |
| `#FFEB3B` 純黄 | 注意、ハザード | カジュアルすぎてコピー「冷静な共犯者」トーンと齟齬 |

**結論**: 黄色系は Amazon とのブランド衝突を招く。ただし **論破の弾薬（死蔵資産・使い切れ達成率）** など、ユーザーが「眩しい真実」に直面する瞬間には `gold #D4B062` を限定使用。

### 3.3 緑系（健全・成功）— 不採用

| 色 | 連想 | なぜ YUDANE に合わないか |
|---|---|---|
| `#4CAF50` グリーン | 健全、成功、承認 | 「健全な達成」印象で、ダメ化ループと齟齬する |
| `#8BC34A` ライム | 新鮮、安全 | 「このサービスは大丈夫」印象で、倫理自白（§9）と矛盾 |

**結論**: 緑系は YUDANE が演出したい「静かな誘惑 × 自白による倫理性」の両立を崩す。完全に不採用。

### 3.4 純粋なピンク — 不採用

| 色 | 連想 | なぜ YUDANE に合わないか |
|---|---|---|
| `#FF69B4` ホットピンク | 派手、若年層 | 「強く誘う」印象で押し付けがましい |
| `#FFB6C1` ライトピンク | 優しい、女性的 | ペルソナ（悠介 28 歳男）のトーンと齟齬 |

**結論**: 純粋なピンクは「感情を煽る」方向に寄りすぎる。代わりに **Cold Rose（薄紫ピンク）** を採用し、親密さと冷ややかさの両立を実現。

## 4. UX 倫理の観点からの配色制御

### 4.1 NG-6 精神衛生境界との整合

冷却モード発動時（FR-AUTH-04 / NG-6 / ng-scenarios.md）は **色調を強制変更** する:

| 通常時 | 冷却モード発動時 |
|---|---|
| Indigo 背景 + Rose/Cyan アクセント | **グレースケール一色**（アクセントを剥奪）|
| 論破モーダルは常時可動 | 論破モーダルは非表示 |
| Amazon リンクが Cyan で強調 | Amazon リンクは無効化・グレーアウト |

これは **色彩的撤退 UX** として、ユーザーに「今は休め」を視覚で伝える。隠さず、明確に。

### 4.2 NG-8 Amazon Associates Operating Agreement との整合

Cyan で強調する Amazon 遷移リンクには、**常に以下を併記する**:

- 「Amazon に飛ばすよ」確認オーバーレイ（`mockup/index.html` の `#buyOverlay`）
- 「決済は Amazon 側で完結 — YUDANE は紹介だけ（Associates）」の注記
- 広告表記バッジ（実装時に追加、現モックでは注記文のみ）

Cyan の視覚的強調 ≠ 隠蔽ではなく、**「出口」であることを明示する責任** を負う色としての採用。

### 4.3 WCAG 2.2 AA の観点

要件書 §6.6 アクセシビリティに基づき、主要コントラストを確認:

| 組み合わせ | コントラスト比 | WCAG 2.2 AA 基準 | 判定 |
|---|---|---|---|
| Indigo 背景 `#0A0E2A` × 白文字 `#FFFFFF` | 16.89:1 | 4.5:1 | ✅ |
| Indigo 背景 `#0A0E2A` × Rose `#E8B4D0` | 9.42:1 | 4.5:1 | ✅ |
| Indigo 背景 `#0A0E2A` × Cyan `#4DE1FF` | 11.87:1 | 4.5:1 | ✅ |
| CTA Rose グラデ × 濃紺文字 `#0A0E2A` | 9.32:1 | 4.5:1 | ✅ |
| 補助 `ink-3 rgba(255,255,255,0.28)` × Indigo | 3.07:1 | 3:1（UI コンポーネント） | ✅ |

全組み合わせで WCAG 2.2 AA を満たす。ただし §6.6 の注記通り、**WCAG 全面準拠は宣言しない**（実機検証・専門レビュー未実施のため）。

## 5. 競合 EC アプリとの色比較

| サービス | 主要色 | ブランド戦略 | YUDANE との差分 |
|---|---|---|---|
| Amazon Shopping | Navy `#232F3E` + Orange `#FF9900` | 「世界最大のラインナップ」「最安」訴求 | 明るく能動的 |
| 楽天 | Red `#BF0000` + 白 | 「ポイントで得する」能動的購買 | 警告色が主役 |
| Instagram Shop | グラデーション（紫→オレンジ→黄）+ 白 | 「映える」「トレンド」 | 派手で能動的 |
| Honey / Rakuten Rebates | Bright Yellow + Black | 「お得情報」 | カジュアル |
| **YUDANE** | **Indigo + Cold Rose + Cyan** | **「迷う瞬間の冷静な共犯者」** | **静的・瞑想的・自白あり** |

YUDANE だけが「明るく能動的な購買促進」を避け、**「夜の迷いに寄り添う」** トーンを採用している。これは ②迷う瞬間に介入する戦略（`market-positioning.md` 軸 1）と整合する配色判断。

## 6. 変更時のガバナンス

本配色は以下の場合のみ変更可能:

- **KPI 再キャリブレーション後**: 予選 / 決勝のデータで深夜帯利用比率が目標を下回った場合、背景明度を再検討
- **Approved Mobile Application 審査での指摘**: Amazon 側から Cyan リンクの強調度が規約違反とされた場合（NG-8 整合）
- **NG-6 境界の実計測**: ユーザーテストで Rose 配色が「煽られている」と感じられた場合

変更履歴は本書末尾に追記する。
