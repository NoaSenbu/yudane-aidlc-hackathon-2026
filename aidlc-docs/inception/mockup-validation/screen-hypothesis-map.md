# 画面 × 仮説検証マップ

> モックアップ 6 画面それぞれが検証する UX 仮説と、現時点での判定を一覧化する。
> モックアップ実体: `mockup/index.html`

---

## 0. この文書の読み方

各画面について、以下を記述する:

- **検証したい仮説**: その画面が成立することで何が立証されるか
- **判定**: モックアップを操作した結果の現時点判定（✅ / ⚠️ / ❌）
- **現時点での根拠**: 静的 HTML で確認できた事実
- **予選 5/30 までに追加検証する項目**: 実装で確かめる項目
