## 🎯 Part 1: 「ダメにする」方向性を決める

### Question 1: どの領域の「ダメ」を狙いますか？

人をダメにする領域として、主にどの軸を攻めたいですか？

A) 🛌 **怠惰系** — 体を動かさない、起き上がらない、人間を「芋」にする

* 例: 寝たままスマホ操作を代行してくれるbot / リモコンを取りに行く気力ゼロの人のための「目線で全家電操作」サービス / ソファから動かずに夕食が完成する仕組み

B) 🍜 **食欲・快楽系** — 食べすぎ・飲みすぎ・脳内報酬系の暴走を誘発

* 例: 深夜に罪悪感ゼロで二郎系ラーメンを正当化するAIカウンセラー / 食べた分だけ「実は痩せた計算」になるカロリー記録アプリ / 冷蔵庫が「今食べないと腐るよ」と24時間囁いてくる

C) 🧠 **思考停止系** — 意思決定・選択・判断をすべて代行してしまう

* 例: Netflixで何を観るか悩む間もなく勝手に再生開始するサービス / 今日の服・昼食・返信内容を全部決めてくれるAI執事 / Yes/Noの2択すら代わりに押してくれるボタン

D) 📱 **依存・中毒系** — 気づいたら何時間も使っている、ドーパミン漬け

* 例: TikTokより抜け出せない「無限ほめてくれるショート動画」アプリ / 猫の動画だけが流れ続けて時間が溶けるサービス / 通知を開くとまた通知が来るループbot

E) 💸 **散財系** — 財布のひもが緩む、衝動買い、浪費を快感に変える

* 例: 「買わない理由をAIが全部論破してくれる」EC購入アシスタント / ガチャ演出で日用品を買わせるネットスーパー / 散財するほどレベルアップするゲーム化家計簿

F) 🗣️ **人間関係ダメ化系** — コミュニケーション能力を退化させる

* 例: LINEの返信を全部AIが代筆して、もう自分では文章が書けなくなるbot / 既読スルーの言い訳を無限生成してくれるサービス / 親への電話をAI音声で代行し続けて自分の声を忘れる

G) ⏰ **先延ばし系** — タスクを永遠に後回しにさせる

* 例: ToDoを追加するたびに「まだ大丈夫」と励ましてくれるリマインダー / 締め切りを自動で延長交渉してくれるAI秘書 / サボり続けた日数を誇らしく可視化するアプリ

X) Other (please describe after \[Answer]: tag below)

\[Answer]:Eの散財系で「買わない理由をAIが全部論破してくれる」EC購入アシスタントの方針で進めたいです。エージェント型コマースの要素も入れてみたいです。

## ✍️ Part 5: 自由記述（超重要）

### Question 13: すでにある「ダメ化アイデア」の種を教えてください（任意だが推奨）

ブレストの出発点になります。ラフな一行でも、複数候補でも、ネタ寄りでもOKです。

例:

* 「朝起きたくない人のために、二度寝を正当化するAI秘書」

* 「Netflix選びを完全に放棄できる、脳波で自動再生するソファ連動サービス」

* 「筋トレをサボった言い訳を毎日自動生成してSNSに投稿するbot」

* 「カップ麺の蓋を押さえる時間を、代わりに瞑想してくれるアプリ」

\[Answer]:
\
下記がQuestion12までに回答していく中で出てきたアイデアです。\
家計簿アプリの逆を行く、「いかにお金を使うべきか」を提示する専用アプリです。

実装形態: iOS/Androidネイティブアプリ（銀行/カードAPI連携）

導線: スマホのホーム画面に「今日の使える金額（＝使い切るべき金額）」をデカデカと表示。

「駄目にする」ポイント:

逆・家計簿: 貯金が増えると「死蔵されている資産がかわいそうです。これを買えば経済が回ります」と通知。
エージェント型代理購入: ユーザーの趣味嗜好から、AIが勝手に「これ、絶対好きだと思って確保しておきました（決済直前状態）」と、リール動画のような縦型UIで次々と商品をプレゼン。
ストレス連動: ユーザーの歩数やカレンダーの忙しさを検知し、「今日は頑張ったから、これくらいのご褒美は当然です」と、疲労に付け込んだ提案。
