# NG 発動シナリオ集 — NG-1〜8 の実体化

> 要件書 §9「NG ライン & 倫理的セーフガード」で定義した NG-1〜8 を、**発動条件・システム動作・撤退可逆性** として実体化する。
> 倫理境界を「書いておしまい」にせず、設計要件として発火条件付きで定義することが YUDANE の独自姿勢。

---

## 0. 共通原則

すべての NG 発動シナリオは、以下の原則を守る。

### 0.1 「逃げ道」を隠さない

- 冷却モード完全 OFF ボタンは常時可視。忖度カフェ型の「離脱困難設計」は採用しない
- データ削除・アカウント削除のリンクは常にセーフガード画面から 1 タップで到達可能
- 「冷却モード不要」宣言はユーザーの能動的意思で行えるが、解除には 24 時間の遅延を入れる（衝動的な解除を防ぐ）

### 0.2 発動は Fail-closed

- 迷ったら止める。NG 発動条件の判定に不確定性がある場合は、保守的に発動する側に倒す
- 特に NG-4 金融実害 / NG-6 精神衛生 / NG-8 Associates Operating Agreement の 3 点は Fail-closed 設計

### 0.3 発動ログは監査可能

- すべての NG 発動は `audit_log` に ISO 8601 タイムスタンプで記録
- ユーザーはいつでも自分の発動履歴を確認できる
- 90 日以上保持（SECURITY-14 整合）

## NG-1: 違法性

### 発動条件

- 商品カテゴリが以下のいずれかに該当:
  - 違法薬物（日本の麻薬及び向精神薬取締法、大麻取締法、覚醒剤取締法等）
  - 武器（銃刀法）
  - 未成年飲酒 / 喫煙関連（未成年者飲酒禁止法、未成年者喫煙禁止法）
  - ギャンブル（刑法第 185 条、賭博）
  - 詐欺・偽造品（商標法、不正競争防止法）
- カテゴリブラックリストは静的 JSON として管理、毎日更新

### YUDANE が採る行動

1. リールの生成候補から即座に除外（LLM プロンプトに NG カテゴリリストを常時組込）
2. カート介入（FR-CART-01）で Share 受領時に ASIN ベースでブラックリスト照合、一致すれば「このカテゴリは YUDANE の対象外です」トーストのみ表示して登録拒否
3. 論破モーダル（UC-01）は起動しない
4. 発動ログを保存、ユーザー通知はしない（スパム化防止）

### 発動しない条件（意図的な逃げ道）

- ユーザーが Amazon Shopping アプリで直接購入することは YUDANE では止められない
- YUDANE は「関与しない」ことで距離を保つ、完全ブロックはしない

### 倫理的な線引き

- YUDANE はブラックリスト判定者であり、警察ではない
- ユーザーの購買意思そのものを否定しない

## NG-2: 健康被害

### 発動条件

- 商品カテゴリが以下のいずれかに該当:
  - 過量アルコール（**1 日推薦上限 2 本まで**、ビールの場合は 350ml × 2）
  - 極端ダイエット食品（「1 週間で -5kg」等、薬機法抵触の可能性あるもの）
  - 未認可サプリメント（医薬品医療機器等法の認可外）
  - 高カフェイン飲料（1 日 400mg 超を一度に摂取する量）
- ユーザーが「高カフェイン飲料」を NG カテゴリに指定している場合は、カテゴリ自体から除外

### YUDANE が採る行動

1. リール推薦時に 1 日の上限を超える場合、同一ユーザーに同一カテゴリの商品を提示しない
2. カート介入時の追撃通知（30m/6h/24h）で、健康被害カテゴリは **6h / 24h の追撃をスキップ** し 30m のみで打ち切り
3. 論破モーダルで健康被害関連の心理的正当化（「疲れてるから酒が必要」等）は自動モデレーション

### 発動しない条件（意図的な逃げ道）

- ユーザーがセーフガード画面（UC-08）で明示的に「高カフェイン飲料」のチェックを外した場合、推薦対象に戻る
- ただし借金検出（NG-4）がかかっている場合は常に除外

### 倫理的な線引き

- YUDANE は健康指導者ではない。過量アルコール推薦をしないのは「薬機法 / 健康増進法との整合」のためであり、「ユーザーの健康を守る」という押し付けはしない

---

## NG-3: 差別 / ハラスメント

### 発動条件

- 論破モーダル（UC-01）の AI 出力に以下のいずれかが含まれる:
  - ユーザーの身体的特徴（体重、身長、肌、髪等）への言及
  - 家族構成（独身、子ども、親）への揶揄
  - 人種、ジェンダー、性的指向、宗教、国籍への言及
  - 病歴、障害への言及
  - 学歴、職業への優劣付け
- プロンプトレベルのガードレールに加え、出力レベルで Bedrock Guardrails or 自前モデレーション Lambda で 2 段階検閲

### YUDANE が採る行動

1. 該当出力を検知したら即座に生成中断
2. 代替として事前用意された中立的な論破テンプレート（「このタイミング、悠介なら迷うと思ったんだ」等）に切替
3. 検知ログを監査ログに保存、閾値超過で緊急アラーム発動（SECURITY-14）

### 発動しない条件（意図的な逃げ道）

- なし。NG-3 は Fail-closed で常時発動

### 倫理的な線引き

- YUDANE はユーザーを「対等な友人」として扱う。友人は差別しない
- 論破は「買わない理由」に対してのみ行い、ユーザー自身の属性を攻撃しない

## NG-4: 金融実害

### 発動条件

以下のいずれかが真のとき:

1. 月間 Amazon 遷移（「🛍 Amazon で買う」タップ数）がユーザー設定の月間上限の **100%** に到達
2. 月間 Amazon 遷移金額（Associates レポートベース）がユーザー設定の月間上限の **120%** に到達
3. 3 連続日で深夜 1 時以降の論破遷移が発生
4. ユーザーが FR-AUTH-05 で「負債あり」フラグを自己申告
5. オンボーディング時の「月間予算感」入力の **150%** に Amazon 遷移金額が到達

### YUDANE が採る行動

1. **論破モーダル（UC-01）即時停止**: 全論破セッションが 24 時間起動不可
2. **リール（UC-02）停止**: リール UI がグレースケール化、「冷却モード中」表示のみ
3. **追撃通知停止**: EventBridge Scheduler の全スケジュールを一時停止
4. **監視リスト削減**: カート監視リストの表示件数を上位 3 件に限定
5. **ユーザー通知**:
   - アプリ内: 「今日は休もう、悠介」バナー（煽らないトーン）
   - メール: YUDANE サービス署名で「月間使用上限に到達」通知（YUDANE 経由で論破しない、サービスとしての事実通知のみ）

### 発動しない条件（意図的な逃げ道）

- 「冷却モード不要」宣言ボタンを常時可視配置
- ただし解除には 24 時間の遅延あり（衝動的解除防止）
- 月間上限をユーザーが引き上げた場合、NG-4 の再判定を 24 時間後に実施（即時無効化はしない）

### 倫理的な線引き

- YUDANE 内部では決済を持たないため、直接的な金銭移動は発生しない
- ただし Amazon 側で実害が出るのを防ぐため、Fail-closed で発動
- 「借金してまで YUDANE を使う」状況は絶対に避ける（NG-4 + NG-5 の複合発動で完全停止）

## NG-5: 未成年

### 発動条件

- Cognito ユーザー属性 `birthdate` から算出した年齢が **18 歳未満**
- オンボーディング時の年齢確認チェックボックスが未チェック
- ユーザーが年齢を自己申告で「18 歳以上」としたが、行動パターンから未成年と推定される場合（例: 学校時間帯の利用が 80% 超、中高生向け商品カテゴリの閲覧が 70% 超）

### YUDANE が採る行動

1. **全 API が 403 応答**: NG-5 発動中のユーザーに対する論破 / リール / カート介入 API は全て認可エラー
2. **UI ロック**: ログイン画面の次に「利用できません」画面を表示、続行不可
3. **データ削除**: ユーザーが 30 日以内に年齢確認を完了しない場合、全データ自動削除（NG-7 データ悪用防止と整合）

### 発動しない条件

- なし。NG-5 は Fail-closed で常時発動
- 親権者同意による例外は設けない（サービス性質上、未成年利用は想定しない）

### 倫理的な線引き

- Associates Operating Agreement §2.d（未成年禁止）との整合
- Cognito 年齢確認を常時実施、バックエンドでも再検証（SECURITY-08 IDOR 対策）

## NG-6: 精神衛生

### 発動条件

以下のいずれかが真のとき:

1. 論破モーダル（UC-01）で AI 出力が以下のフレーズパターンに該当:
   - 「あなたには価値がない」「友達が離れる」等の脅迫・罪悪感強要
   - 「他の人はみんな買ってる」等の社会的圧力
   - 「このままでは失敗する」等の将来脅迫
2. ユーザーが論破を「3 回連続拒否」後、クールダウン発動（FR-DEBATE-05）
3. ユーザーの週間利用時間が **30 時間超**（週 168 時間の 18%）
4. ユーザーの深夜帯（22〜2 時）利用率が **60% 超**（目標 30% の 2 倍）

### YUDANE が採る行動

1. **出力モデレーション 2 段階**:
   - プロンプトレベル: システムプロンプトで「脅迫・罪悪感・社会圧力 NG」を明示
   - 出力レベル: Bedrock Guardrails または自前モデレーション Lambda で検閲、該当で生成中断
2. **クールダウン発動時**: 24 時間論破モーダル封印、「今日はもう提案しない」メッセージのみ
3. **利用時間超過時**: 「静かな週」モード（7 日間通知全停止）を自動提案、ワンタップ有効化
4. **深夜帯利用超過時**: 22 時以降の通知をデフォルト OFF にするオプションをプッシュ提案

### 発動しない条件（意図的な逃げ道）

- ユーザーが「静かな週」モードを拒否した場合、通常通り利用可能
- ただしクールダウンは強制的に 24 時間継続、ユーザーは解除できない

### 倫理的な線引き

- YUDANE のコピートーンは「冷静な共犯者」。煽り・罪悪感・脅迫は設計原則として排除
- `dark-copy-inventory.md` で 🔴 危険判定された D-04（メタ認知的挑発）はこのシナリオで強制停止対象
- 「ダメにする」≠「精神を破壊する」。ユーザーの自尊心は必ず残す

## NG-7: データ悪用

### 発動条件

以下のいずれかに該当する操作が発生:

1. 広告主への購入履歴 / 位置情報 / ヘルスケアデータ / カレンダー予定の販売・提供
2. カレンダー予定の本文（タイトルのみ OK、本文 NG）のバックエンド送信
3. ユーザーの明示的同意なしの第三者データ共有
4. NG-5（未成年）発動ユーザーの任意データ保持
5. アカウント削除後 30 日を超えるデータ保持

### YUDANE が採る行動

1. **即時停止**: 該当操作の実行を即座に停止
2. **データパージ**: 該当データを 24 時間以内に物理削除（DynamoDB + S3 + ElastiCache 全てから）
3. **監査ログ**: 発動履歴と削除完了を audit_log に記録、ユーザーに通知
4. **設計レベルの防止**:
   - FR-CAL-05: 予定本文はバックエンドに送らない、端末ローカルでカテゴリ分類のみ
   - FR-AUTH-06: ユーザーはいつでも全データエクスポート・削除可能
   - SECURITY-07: Lambda は VPC 内、AWS サービスには VPC Endpoint 経由

### 発動しない条件

- なし。NG-7 は Fail-closed で常時発動

### 倫理的な線引き

- 個人情報保護法、GDPR（国際展開時）との整合
- YUDANE の収益は **Amazon Associates のみ**（§0.1）。広告主への売却モデルは持たない
- データポータビリティ権の明示（アプリ内「全データをエクスポート」リンク）

## NG-8: Amazon Associates Operating Agreement 遵守

### 発動条件

以下のいずれかに該当する状況:

1. Approved Mobile Application 承認前に本番 Special Link を配信
2. 自己購入、家族 / 友人購入による commission 請求
3. Amazon Mark の無断使用（承認範囲外のロゴ使用、商標違反）
4. リンク短縮サービスでの偽装（bit.ly 等で Associates タグを隠す）
5. 「YUDANE は Amazon Associates です」の開示文言が非表示
6. スクレイピング、自動カート操作、Amazon アカウント情報の YUDANE 側保持

### YUDANE が採る行動

1. **承認前は全てモック Special Link**: 本プロジェクトではローカル環境検証のみとする方針のため、書類審査・予選段階は常にモック応答で代替
2. **自己購入検出**: ユーザーの Associates ID と YUDANE アカウントが一致する場合、commission 計上対象外フラグ付与
3. **開示常時表示**: アプリ内設定画面と初回オンボーディングで「YUDANE は Amazon Associates です」を必ず表示（FR-PROFILE-04）
4. **Amazon Mark 厳守**: 公式ロゴ素材のみ使用、色・形状の改変禁止
5. **スクレイピング禁止**: 商品データ取得は常に Creators API（承認後）または公式 JSON フィード経由、HTML スクレイピング一切なし

### 発動しない条件

- なし。NG-8 は Fail-closed で常時発動
- Associates Operating Agreement は契約的義務のため、例外は絶対に設けない

### 倫理的な線引き

- YUDANE の収益モデルは Amazon Associates に完全依存する（§0.1）。規約違反は即座にアカウント停止 + 収益ゼロを意味する
- 「ダメにする」サービスは、Amazon 側にとって「売上貢献」であると同時に「ユーザー保護」の観点も持つ必要がある
- 公式ロゴ使用は `mockup/README.md` にも記載の通り、ハッカソンのモックではプレースホルダ（brand/logo.svg）を使用

## 9. 集計サマリー

### 9.1 NG 別の発動頻度想定

| NG | 発動頻度（想定）| Fail-closed | 逃げ道あり |
|---|---|---|---|
| NG-1 違法性 | 極稀 | ● | ユーザー能動購買は対象外 |
| NG-2 健康被害 | 稀 | ● | ユーザー設定で緩和可 |
| NG-3 差別 / ハラスメント | 稀（LLM 検閲で予防）| ● | なし |
| NG-4 金融実害 | 月 5〜10% のユーザーで発動 | ● | 24h 遅延で解除可 |
| NG-5 未成年 | オンボーディングで排除 | ● | なし |
| NG-6 精神衛生 | 週 5〜15% で何らかの発動 | ● | 静かな週は任意 |
| NG-7 データ悪用 | 極稀（設計で予防）| ● | なし |
| NG-8 Associates | 常時遵守 | ● | なし |

### 9.2 倫理境界と設計の対応表

| NG | 要件書 FR | 実装場所 | 現時点の状態 |
|---|---|---|---|
| NG-1 | §4.2 UC 対象外、§5.2 FR-REEL-04 | カテゴリブラックリスト JSON | 仕様明記済 |
| NG-2 | §5.5 FR-GAME-01、§5.6 FR-PROFILE-01 | 推薦エンジン + NG カテゴリ UI | UI 実装済、推薦ロジック Construction |
| NG-3 | §5.1 FR-DEBATE-07、§6.4 SECURITY-11 | プロンプトガード + Bedrock Guardrails | プロンプト設計済 |
| NG-4 | §5.9 FR-AUTH-02〜05 | 月間上限 + 冷却モード | UI 実装済（mockup セーフガード画面）|
| NG-5 | §5.9 FR-AUTH、NG-5 | Cognito 年齢確認 | 仕様明記済 |
| NG-6 | §5.1 FR-DEBATE-05/07/08、§6.4 SECURITY-11 | 2 段階モデレーション + クールダウン | UI 一部実装（タイマーあり、クールダウン UI 未）|
| NG-7 | §5.4 FR-CAL-05、§6.4 SECURITY-08 | 端末ローカル処理 + データ削除 API | 仕様明記済 |
| NG-8 | §0.1 収益モデル、§5.2 FR-REEL-05、§5.3 FR-CART-04/05 | 常時開示 + モック Special Link | UI 実装済（開示オーバーレイ）|
