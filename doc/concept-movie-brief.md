# YUDANE コンセプトムービー 制作ブリーフ（30秒・全編AI生成）

## 1. 作品コンセプト

30秒の実写風ショートフィルム。テーマは「便利さに判断をゆだねていく人」。

主人公は、夜にひとりで通販アプリを眺める20代後半の男性。買うか迷う時間を、購入を提案してくれるアプリに任せているうちに、「自分で決める」という行為を少しずつ手放していく。その静かな行動変容を、落ち着いた少し不思議な余韻で描く。

物語の流れ: 迷う → 任せる → 提案が届く → 受け入れる → 落ち着く。
狙う感情: 共感 → 納得 → ふと我に返るヒヤッとした余韻。淡々と、説教調にしない。

## 2. 映像の方針

- 構成単位: 1ショット約6秒 × 5ショット = 30秒。
- 画作り: 実写風。浅い被写界深度、穏やかなフィルムグレイン。主光源はスマートフォン画面の柔らかい光。
- カラー: 深いインディゴ＋紺をベースに、ソフトなローズピンクと淡いシアンの発光。
- 雰囲気: 静かで落ち着いた、少しだけ不思議な余韻。手持ちの微細な揺れ。
- 登場人物: 架空の20代後半の日本人男性。
- 避ける描写: 指や手の崩れ、ぼやけ、低品質、。

## 3. 台本（5ショット）

各ショットは「映像（日本語で具体的に）」「ナレーション」「テロップ」で構成する。映像欄をそのまま生成指示として使える粒度で書いている。

### ショット1（0–6秒）— 迷う
- 映像: クローズアップ。夜の落ち着いた室内で、若い日本人男性の手がスマートフォンを持ち、画面の光が顔を半分だけ照らす。画面には抽象的な光の形でできた通販アプリ風のカートが映る。親指を画面の上で止めたまま、落ち着いた思案顔で迷っている。深いインディゴと紺の色調、ソフトなローズピンクと淡いシアンの発光。カメラはゆっくり寄る（スロー・プッシュイン）。
- ナレーション: 「あの、それ……まだ買うか迷ってるんすか？」
- テロップ: まだ迷ってるの？

### ショット2（6–12秒）— 逡巡
- 映像: 同じ男性が、通販アプリで商品をカートに入れる→前の画面に戻る→またスクロールする、を繰り返す。考えあぐねた表情。画面の柔らかい光が顔の上で静かに移ろい、背景の壁掛け時計が速く進む。深いインディゴと紺の色調。穏やかなタイムラプス風のカット。
- ナレーション: 「40分迷うくらいなら、AIに任せた方が早くないですか？」
- テロップ: 任せた方が早い？

### ショット3（12–18秒）— 提案が届く
- 映像: 落ち着いた暗めの室内。スマホ画面がいったん暗くなり、メッセージ通知がひとつ柔らかく灯る。ローズとシアンの光が周囲に広がり、男性が軽い好奇心で振り向く。深いインディゴと紺の色調。カメラは光るスマホへゆっくり寄る。
- ナレーション: 「ほら、30分後。ちゃんと迎えに来ますよ。」
- テロップ: 30分後、また届く

### ショット4（18–24秒）— 受け入れる
- 映像: 男性の肩越しにスマホを捉える。抽象的な形でできたメッセージの吹き出しが画面に次々と浮かび、ひとつずつ少しだけ明るくなる。表情が迷いから納得へ和らぎ、シアンの光が顔に広がる。深いインディゴと紺の色調にローズピンクとシアンの発光。カメラはゆっくり一定速度で寄る。
- ナレーション: 「時給換算11分っすよ。会議23本こなした人が、それくらい自分に使えないって、逆に変じゃないですか？」
- テロップ: 事実 × 気持ち、同時に

### ショット5（24–30秒）— 落ち着く、そして余韻
- 映像: 手が発光するボタンを軽くタップするクローズアップ。画面が柔らかく温かい光で弾け、男性は落ち着いた表情になる。やがて場面はゆっくり深いインディゴの黒へ移り、中央にローズとシアンの光点がひとつ静かに残る。クローズアップから始まり、静かな暗転へフェード。
- ナレーション: 「はい、買えた。気分も、ちょっと治った。……それ、"自分で決めるの"、やめた瞬間ですけどね。」
- テロップ: 委ねるほど、ダメになる。（ロゴ「YUDANE」と一緒に最後に表示）

## 4. 編集メモ

- 5ショットを順に連結。ショット3の暗転とショット5の暗転でリズムを作る。
- テロップは1カット1ワード。最後のロゴカットだけ間を置いて余韻を作る。
- ナレーションは早口・理屈っぽい架空キャラの声。BGMは軽快で少し皮肉っぽい素材を当て、最後で抜いて余韻。
